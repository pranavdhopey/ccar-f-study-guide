4Real agents (example 5)

Parallel tool calls
One reply can hold several tool_use blocks. Run them all, send all results back in one user message, matched by tool_use_id.
A tool fails?
Don't crash. Send a tool_result with the error text and is_error: true. Claude can adapt.
Any other stop_reason (max_tokens, refusal...): not finished normally. Stop and look. Never assume it means tool_use.
