Multi-Agent Orchestration

CCAR-F  ·  Domain 1  ·  Task 1.2  ·  hub-and-spoke is THE pattern

1What is it? (in plain words)

  • Several Claude agents working on one big task.
  • A coordinator splits the task up. Subagents each do one part (search, read documents, write...).
  • Think head chef + station cooks. Cooks never shout across the kitchen: every order goes through the chef.
Coordinator =
split + delegate
+ check + combine

2Hub-and-spoke

Why one hub?  Observability (log everything in one place)  •  consistent error handling  •  controlled information flow (the coordinator decides who sees what).

3Isolation: the big one

A subagent starts BLANK. It does not inherit:
  • the coordinator's conversation history
  • the coordinator's system prompt
  • other subagents' results
  • any shared memory (and a 2nd run knows nothing of the 1st)
So put EVERYTHING it needs in ITS prompt. Output wrong or thin? Blame the origin, not the output: check what the coordinator gave it.

4The coordinator's 4 jobs

1. Dynamic selection
Invoke only the subagents the query needs. A simple fact needs only web search.
2. Scope partitioning
Give each subagent different subtopics or source types. No overlap.
3. Iterative refinement
Check the draft for gaps, re-delegate a targeted query, re-check. Repeat.
4. Central routing
All communication runs through the coordinator.

5The narrow decomposition failure

A subtopic nobody is assigned never gets researched.
Café costs split into only ingredients + rent → the report misses wages, energy, insurance. Every subagent did its job.
Missing whole topics (scope) → suspect the decomposition. Thin section (depth) → check that subagent's prompt and tools.

6Exam traps

  • Blaming a downstream subagent for a gap the coordinator's decomposition caused.
  • Assuming shared memory or inherited history.
  • Direct subagent-to-subagent messaging as an "efficiency" fix.
  • Full pipeline for every query + caching unused results to save cost. Extra runs still cost latency and API calls.
Current state: in Claude Code a subagent can spawn subagents (up to 3 layers). "Never" is an exam simplification. The exam keys hub-and-spoke.
Memory trick:   "everything through the chef, and tell the cooks everything"
